# Patterns

_Generated by `npm run patterns`. The 8 sections are the original component list; each holds the component types found in the sample (the core type first, then discovered ones), and each type has one page. Counts come from the 250-block sample, so they show relative frequency in the sample, not across all 181 sites. Contact sheets live in `methodology/variants/` (committed); the per-example links open full crops from the local `archive/` (not in git, run `npm run archive && npm run blocks`)._
